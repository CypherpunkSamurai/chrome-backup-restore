FAQ

Answers to the questions this tool cannot fix, and the ones it can.

How to export or copy extension data

Each tab exports on its own. Open the tab, press Export, and Chrome writes a JSON file to your default download folder. The file name carries the tab and a timestamp, for example cookies-20260927-141530.json.

To get every kind of data, run Export once per tab: Extensions, Bookmarks, History, Cookies, and Storage. Nothing lands in one file, because the five formats have different shapes and one tab writes one file at a time.

Import reads the matching file back. Each tab refuses a file from another tab, so open the tab that matches the file.

Why do Google, Meta and WhatsApp log me out after import

Those sites tie the session to more than the cookie. Google, Facebook, Instagram and WhatsApp each keep a signed token in localStorage, and part of it lives in IndexedDB. Import restores cookies, and it restores localStorage only for origins in a Storage file, so a Cookies-only import leaves the token missing and the site drops the session.

Three other causes hit the same result:

A cookie the site re-issues on a timer. A restored session cookie can be older than the token the server already holds, so the server wins.

A device or IP change. A moved profile, a VPN or a new network reads as a new device, and these sites end the old session on purpose.

Certificate pinning on .google.com and Meta subdomains. The pinned key stays in the platform keystore, not in the profile, so a cookie restored onto a fresh profile never matches it.

To restore the session, import a Storage file that was taken with the site open in a tab, in this order: close the site tabs, import the Storage file, import the Cookies file, then reload. If the site still signs you out, the token has expired on the server and a password login is the only fix. No extension resurrects a session the site already revoked.

Why did an extension import open Web Store pages

Chrome blocks extensions from installing other extensions, so import can only enable or disable what you already have. An extension listed in the file but missing from the profile opens its Chrome Web Store page in a background tab, because the store is the only route left.

Why do history entries land with today's date

chrome.history.addUrl stamps the current time. The original timestamps stay in the exported JSON for reference, but no API sets them, so imported entries are added oldest first and land on import time.

Why did some cookies fail to import

Chrome refuses a cookie it cannot legally place: a Secure cookie on an http page, a third-party cookie the page blocks, or a cookie whose domain no longer resolves. The status bar counts the failures, and the rest of the file still imports.

Why does bookmark import make duplicates

Import merges into Other Bookmarks and never overwrites, so it cannot tell a fresh folder from one it made on an earlier run. Run it once per file, and clear the imported folder by hand before a second run.

Why is site storage empty on export

sessionStorage exists only in tabs that are open right now, so a site with no open tab exports an empty session half. Tick Also scan history for more sites to reach origins with no open tab. That path opens a temporary background tab, reads the persisted localStorage, and closes the tab, so the session half stays empty by design.

Cookies hold a session, but they are not the whole session. Any site that also keeps a token in site storage asks for a password unless that storage comes back too.
